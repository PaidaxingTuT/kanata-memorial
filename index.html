我与彼方

距离天音彼方毕业，已经过去 126 天了。

我关注 Hololive，只是因为她。她宣布毕业以后，我把整个 Hololive 都取关了。没有她，剩下的对我来说也就没什么意思了。

我是 2021 年开始看她的。那时候学业重，每天两点一线，没有整块的时间蹲直播，基本都是深夜开着台灯，刷 YouTube 和 B 站的切片，或者补她打游戏的录播。日子过得挺枯燥，看她的那一会儿，大概是一天里唯一能松口气的时候。

我很喜欢她。喜欢她打游戏认真得有点较真，平时又笨笨的、憨憨的，一拿起麦克风，唱歌却那么干净好听。隔着屏幕，其实离得很远，可看久了，总觉得她像一个朋友，陪我熬过了很多累的晚上。

毕业直播那天我从头看到尾，一直看到屏幕黑掉。她笑着挥手说再见，我心里一下就空了。那晚根本睡不着，在几个平台上一直转发、留言，写了一堆乱七八糟的话。明明知道留不住，还是想抓住点什么。

今天在 GitHub 上刷到一个纪念她的仓库，里面的画面和代码都很眼熟。我以为自己早就缓过来了，结果还是酸了一下。没想太多，我把它 clone 下来放进了自己的网站，顺手开了这个栏目。算是在自己的角落里，给她留个位置。

我文笔不好，写不出漂亮的话，翻来覆去只会说"喜欢"和"舍不得"。但这确实就是我全部的感受。

我一直知道她身体不太好。以前每次看她因为身体停播，都能感觉到她比谁都着急、比谁都过意不去。现在毕业了，也好，不用再硬撑着去回应那么多期待了。

以后不会再在那个舞台上见到她了，但她陪我走过的那段日子，我会一直记得。我现在也没别的愿望，就希望她好好照顾自己，身体健康，平平安安。

谢谢你来过。

派大星
